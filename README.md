# 📱 TextGrabber

**TextGrabber** is a powerful Android OCR and Text-to-Speech (TTS) application. It allows you to extract text from any screen, copy it, and listen to it using high-quality online voices.

## 🇬🇧 English

### ✨ Features
- **Screen OCR**: Capture any screen and extract text using Tesseract & Google ML Kit.
- **Text Selection**: Select specific words or paragraphs directly from the screenshot.
- **Edge TTS (Online)**: High-quality, natural-sounding voices for Uzbek (Madina, Sardor), Russian (Svetlana), and English (Aria).
- **Auto-Update**: Built-in update checker via GitHub Releases.
- **Smart Text Processing**: Converts numbers to words (e.g., "1" -> "first"), handles Uzbek apostrophes (o', g'), and supports Cyrillic-to-Latin conversion.
- **Multi-Language UI**: Uzbek, Russian, and English interfaces.

### 🚀 How to Use
1. Install the APK and grant the required permissions (Overlay, Accessibility).
2. Tap **"Enable Floating Button"**.
3. Open any app (e.g., Chrome, Telegram) and tap the floating button to capture the screen.
4. Select the text you want to read or copy.
5. Use the top menu to **Copy** or **Read** the text.

## 🇷🇺 Русский

### ✨ Возможности
- **OCR экрана**: Захват экрана и распознавание текста с помощью Tesseract и Google ML Kit.
- **Выделение текста**: Выделяйте нужные слова или абзацы прямо на скриншоте.
- **Edge TTS (Онлайн)**: Качественные голоса для узбекского (Madina, Sardor), русского (Svetlana) и английского (Aria).
- **Автообновление**: Встроенная проверка обновлений через GitHub Releases.
- **Умная обработка текста**: Преобразование цифр в слова (например, "1" -> "первый"), правильная обработка узбекских апострофов (o', g') и кириллицы.
- **Многоязычный интерфейс**: Узбекский, русский и английский языки.

### 🚀 Как пользоваться
1. Установите APK и предоставьте необходимые разрешения (Поверх других приложений, Спец. возможности).
2. Нажмите **"Включить плавающую кнопку"**.
3. Откройте любое приложение (например, Chrome) и нажмите на плавающую кнопку для захвата экрана.
4. Выделите текст, который хотите скопировать или прочитать.
5. Используйте верхнее меню для **Копирования** или **Чтения**.

## 🇺🇿 O'zbekcha

### ✨ Imkoniyatlar
- **Ekran OCR**: Ekrandan rasm olib, Tesseract va Google ML Kit orqali matnni ajratib olish.
- **Matn belgilash**: Skrinshot ustidan kerakli so'z yoki paragraflarni belgilash.
- **Edge TTS (Onlayn)**: O'zbek (Madina, Sardor), Rus (Svetlana) va Ingliz (Aria) tillari uchun yuqori sifatli, tabiiy ovozlar.
- **Avtomatik yangilanish**: GitHub Releases orqali yangilanishlarni avtomatik tekshirish.
- **Aqlli matn qayta ishlash**: Raqamlarni so'zga aylantirish (masalan, "1" -> "birinchi"), o'zbekcha apostroflarni (o', g') va kirillchadan lotinchaga o'girishni to'g'ri qo'llab-quvvatlash.
- **Ko'p tilli interfeys**: O'zbek, Rus va Ingliz tillari.

### 🚀 Qanday foydalanish kerak
1. APK'ni o'rnating va kerakli ruxsatlarni bering (Ekran ustida chizish, Qulaylik xizmati).
2. **"Suzuvchi tugmani yoqish"** tugmasini bosing.
3. Istalgan ilovani oching (masalan, Chrome) va ekranni olish uchun suzuvchi tugmani bosing.
4. Nusxalash yoki o'qish uchun kerakli matnni belgilang.
5. Matnni **Nusxalash** yoki **O'qish** uchun tepadagi menyudan foydalaning.

## 🛠 Tech Stack
- **Language**: Kotlin
- **UI**: Android XML
- **OCR**: Tesseract4Android, ML Kit Text Recognition
- **TTS**: Microsoft Edge TTS WebSocket, OkHttp
- **Update**: GitHub API
